Локальная генерация работает без ИИ. Для Groq AI нужен личный API-ключ. При нажатии кнопки расшифровка и запрос отправляются Groq для обработки. Ключ не записывается в репозиторий, но при использовании в браузере может быть доступен в инструментах разработчика и сетевых запросах; используй его только для личного тестирования и отзови при подозрении на утечку. Для публичного сервиса нужен серверный посредник. Проверь актуальные лимиты Groq; бесплатный план может ограничивать частоту запросов. Видео автоматически не расшифровывается.
